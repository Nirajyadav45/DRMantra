# Dr Mantra: Interactive Growth Pitch

This is a static, single-file presentation. Upload `index.html` to the root of a GitHub repository and enable GitHub Pages.

## Publish with GitHub Pages

1. Log in at https://github.com and select **New repository**.
2. Name it `dr-mantra-pitch`, select **Public**, and click **Create repository**. (On GitHub Free, Pages generally requires a public repository.)
3. Select **Add file > Upload files**. Upload `index.html`, then **Commit changes**.
4. Open **Settings > Pages** in the repository.
5. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
6. Choose `main` and `/(root)`, then click **Save**.
7. Once GitHub finishes publishing, the live URL should be:
   `https://YOUR-USERNAME.github.io/dr-mantra-pitch/`
   Replace `YOUR-USERNAME` with your GitHub username. The actual live link is shown in **Settings > Pages**.
8. Open that live URL in a private/incognito window to check that slides and reel links work. Then share that URL with Takki.

## Notes

- This deck is a single HTML file; no build step, npm, or hosting server needed.
- The closing slide says only **Thank you** and **Let's build what comes next.**
- Google Fonts and Tabler icons are loaded from public CDNs, so the site needs an internet connection to display those fonts/icons.
- The Instagram trend reel cards link to external posts; availability and visibility depend on Instagram.
- **Privacy:** GitHub Pages is publicly accessible. The deck includes budget and forecasts, so get approval before publishing it publicly. If these figures are confidential, use a private, access-controlled sharing method instead.
